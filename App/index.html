  1. גשו ל-Google Cloud Console → Credentials
  2. לחצו Create Credentials → OAuth client ID → סוג Web application
  3. תחת Authorized JavaScript origins הוסיפו: https://snddigitalagency.com (ואם בודקים מקומית גם http://localhost עם הפורט שלכם)
